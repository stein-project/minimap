# Minimap

A [Stein Loader](https://github.com/Stein-Project) mod for Minecraft 1.8.9: a minimap on the HUD grid, with the terrain
from above or radar only, and players, mobs and spawners.

It is an addition, outside the Stein Project's default mods: some servers do not allow a minimap, so check the rules of
where you play. A server can turn it off with the `minimap` feature.

It used to be part of the HUD: the first time it runs, it takes the choices the player had there, and the element stays
in the same place on the screen.
